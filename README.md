# LUÍS-MAN: FUGA DOS QUARTOS

Jogo web arcade cómico em ficheiro único, inspirado em labirintos clássicos de perseguição, com identidade original.

## Como abrir

1. Garante que tens a imagem opcional em `public/luis.jpg`.
2. Abre diretamente o ficheiro `index.html` num browser moderno.
3. Também podes publicar a pasta no GitHub Pages; não há build, servidor, npm ou dependências para o jogo.

## Testar no StackBlitz

1. Abre o repositório no StackBlitz.
2. O StackBlitz executa automaticamente `npm start`, que chama apenas o `server.js` local em Node.js.
3. Não há dependências para instalar: o servidor serve ficheiros estáticos e o jogo continua todo dentro de `index.html`.

## Controlos

- Teclado: setas direcionais.
- Telemóvel/tablet: botões tácteis no canto inferior direito.

## Objetivo

Apanha todos os objetos do departamento CASA & CAOS, usa power-ups, evita os quatro clientes cómicos e avança de nível antes que o caos vença o turno.
