# Flappy Baixinho

Mini jogo inspirado em Flappy Bird, feito em HTML, CSS e JavaScript vanilla.

## Abrir no StackBlitz

1. Faz push deste repositório para o GitHub.
2. Abre `https://stackblitz.com/github/OWNER/REPO` substituindo `OWNER/REPO` pelo caminho do repositório.
3. O StackBlitz usa a configuração em `.stackblitzrc` / `package.json` e arranca automaticamente com `npm run dev`.

## Correr localmente

```bash
npm install
npm run dev
```

Depois abre o URL indicado pelo Vite.
